# Books, Certifications & Learning Paths

RedFrameworks v5 adds educational resources as structured metadata rather than mixing them into the tooling catalog.

## Canonical files

- `resources.yaml`: books and certifications;
- `learning-paths.yaml`: objective-driven mappings across frameworks, tools, books and certifications.

## Books

Book entries contain only bibliographic / catalog metadata, a short original note and an official publisher/reference URL. RedFrameworks does not reproduce copyrighted book text.

## Certifications

Certification entries track:

- provider;
- level;
- domains;
- current status;
- official URL;
- short scope note.

The catalog does not rank certifications or claim one credential is universally superior.

## Learning paths

Paths are relevance maps, not mandatory curricula.

Current paths cover:

- OffSec foundations;
- Web & Application Security;
- Cloud & Identity Assessment;
- Purple Team & Detection Engineering;
- Reverse Engineering & Malware Research;
- AI / GenAI Security;
- Secure Software & Supply Chain.
