# Platform v6 · Collaborative Intelligence

Platform v6 changes RedFrameworks from a curated catalog into a **multi-domain intelligence graph with generated defensive context**.

## Core capabilities

- Knowledge Graph 3.0 across frameworks, tools, adversaries, campaigns, sectors, techniques, detections, emulation plans, domain packs and AI security surfaces.
- Campaign Intelligence separated from actor identity.
- Detection Intelligence linking behavior to telemetry, analytics and evidence.
- Verification Engine 2.0 with transparent research dimensions and review SLAs.
- Proposal-only Continuous CTI discovery from public ATT&CK STIX.
- Domain Packs for identity, cloud, AI/GenAI, web/API, supply chain, purple/detection, ICS/OT and IoT/embedded.
- RAG-ready JSONL research corpus generated from canonical records.
- Defensive Adversary Validation Planner.
- Visual Intelligence dashboard with actor type, sector density and campaign timelines.
- API v4 plus Python and TypeScript clients.

## Trust model

Generated relationships never silently become authoritative. Curated edges and generated edges preserve provenance separately. CTI discovery creates review candidates rather than modifying canonical data.

## AI research model

The research corpus is designed for retrieval-augmented analysis. AI-produced relationships should be stored as suggestions until a human reviewer verifies source, scope and confidence.

## Planner boundary

The planner produces a defensive validation brief using actor context, campaigns, authoritative plan references, domain packs, telemetry priorities and evidence requirements. It does not execute offensive procedures.

## API v4

API v4 adds campaigns, detections, domain packs, AI security surfaces, Knowledge Graph 3.0, Verification 2.0, visual intelligence and the research corpus while preserving v1-v3 compatibility.
