# Security Policy

RedFrameworks is primarily a documentation, catalog and static-site project.

## Report a vulnerability in RedFrameworks

For vulnerabilities affecting the repository automation, GitHub Pages implementation or generated site, use GitHub's private vulnerability reporting feature if it is available for this repository.

Do **not** publish secrets, credentials, private assessment evidence or sensitive client information in a public issue.

## Scope

Security reports about third-party projects listed in RedFrameworks should be sent to the relevant upstream maintainer. Inclusion in this catalog does not make RedFrameworks the security contact for those projects.

## Responsible use

The project is intended for authorized testing, labs, defensive validation, detection engineering and research. Contributions should not add destructive operational procedures or sensitive real-world target data.
